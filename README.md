# Komiq — Official Web-Based Manga & Manhwa Reader

Fast, modern, distraction-free manga & manhwa reader. Read thousands of trending chapters in English with zero paywalls.

**Live at:** https://komiq.bond/

## Features
- Lightning-fast reader with dual reading modes (vertical/horizontal)
- 18+ content filter
- Dark mode + brightness control
- Offline support via PWA
- Daily chapter updates
- No paywalls, no ads in reader
